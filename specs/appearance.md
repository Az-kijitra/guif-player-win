# 見た目

上部の「設定」から選び、選ぶとすぐ画面に反映します。

## テーマ

| ID | 受入基準 | 確認 |
|---|---|---|
| A-1 | guif と同じ 6 つのテーマ(Default、Nord、Monokai、Catppuccin、Solarized、Light)を選べる | `finds every theme` |
| A-2 | どのテーマでも、文字が背景に対して読める明るさの差(WCAG AA)を持つ | `is readable on the panels of %s` |
| A-4 | 選んだテーマを、起動し直しても保つ。保存した値が分からなければ Nord にする | 手動 |
| A-5 | 「guif 連動」を選ぶと、guif の設定ファイルと同じテーマにする | 手動 |

A-3 は Android 版のステータスバーに関する基準なので、Windows 版にはありません。A-5 は Windows 版だけの基準です。

## 文字の大きさ

| ID | 受入基準 | 確認 |
|---|---|---|
| A-10 | 文字の大きさを 小(85%)、標準、大(115%)、特大(130%)から選べる | 計画(段階 D) |
| A-11 | ダイアログ、再生画面、メニューの文字も同じ大きさにする | 計画(段階 D) |
| A-12 | 特大でも、最小のウィンドウで上部のバーのボタンが収まり、一覧の文字が欠けない | 計画(段階 D) |
| A-13 | 選んだ大きさを、起動し直しても保つ | 計画(段階 D) |

Windows 版は、ブラウザーの拡大と同じく画面全体を拡大します。Android 版は文字だけを拡大します。
