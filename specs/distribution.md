# インストーラー

配布は Windows 10 / 11(64 ビット版)用の NSIS インストーラーです。現在のユーザーだけにインストールし、管理者権限は不要です。コード署名はありません。

受入基準はすべて `npm run release:sandbox` で確かめます([docs/release.md](../docs/release.md))。

## 新規インストール

| ID | 受入基準 | 確認 |
|---|---|---|
| I-1 | プログラム、アンインストーラー、スタートメニューのショートカットができる | 手動(サンドボックス) |
| I-2 | インストール済みアプリの一覧に版とともに表示される | 手動(サンドボックス) |
| I-3 | `LICENSE.txt` と `THIRD_PARTY_LICENSES.txt` がインストール先にある | 手動(サンドボックス) |
| I-4 | 起動してウィンドウが開き、動き続ける | 手動(サンドボックス) |
| I-5 | データベースは `dev.guif.player` にでき、インストール先には作らない | 手動(サンドボックス) |

## アンインストール

| ID | 受入基準 | 確認 |
|---|---|---|
| I-10 | プログラム、インストール先、ショートカット、一覧の登録が消える | 手動(サンドボックス) |
| I-11 | 既定ではデータが残る | 手動(サンドボックス) |
| I-12 | 「アプリケーションデータを削除する」は既定でオフで、オンにするとデータも消える | 手動(サンドボックス) |
