# キー操作

キーの一覧は[ユーザーマニュアル](../docs/user_manual.md)にあります。ここでは守るべき動きをまとめます。

| ID | 受入基準 | 確認 |
|---|---|---|
| K-1 | 上下、ページ、先頭、末尾へ移動でき、両端で止まる | `moves one item with the up and down arrows`、`stops at both ends`、`goes to the ends with Home and End`、`moves a page and stops at the ends` |
| K-2 | アルバムビューでは上下で行を、左右で 1 つ移動する | `moves a row with the up and down arrows`、`moves one item with the left and right arrows` |
| K-3 | 下の行が短いときは最後の項目へ移動する | `goes to the last item when the row below is short` |
| K-4 | `Shift` + 移動で、移動を始めた行を含めて範囲を選ぶ | `includes the row the movement started from`、`keeps growing as the movement continues` |
| K-5 | フォルダーの行を通っても選択を失わない | `keeps the selection when a folder row is passed through` |
| K-6 | 一覧は `Tab` で一度に抜けられる(行ごとに止まらない) | 手動 |
| K-7 | フォルダーを移動しても、キー操作を続けられる。親へ戻ると元のフォルダーの行にいる | 手動 |
| K-8 | ダイアログを閉じると、開く前の行へ戻る | 手動 |
| K-9 | `Ctrl+Space` は再生を始めない | 手動 |
| K-10 | `Delete` でのプレイリストの削除には確認が出る | 手動 |
| K-11 | フォーカスのある行が見える | 手動 |
| K-12 | 補助的な文字が全テーマで読める | `is readable on the panels of %s` |
